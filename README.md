# TTSassist · 电子声带

为语言障碍者打造的语音沟通助手——输入文字，立刻变成声音。针对游戏等全屏场景做了专门优化：全局快捷键、常驻悬浮球两种方式随时唤起，配合虚拟麦克风输出，在游戏和语音软件里直接"开口说话"。

## 特性

- **悬浮球**：常驻置顶小球，不依赖键盘快捷键，任何游戏里都能用——单击唤起输入浮窗、直接拖拽移动、右键打开菜单；不用时自动贴边半隐藏，不挡画面
- **全屏浮窗**：`Alt+V`（可自定义）在任何界面呼出无边框置顶浮窗，输入文字 → 自动生成语音播放
- **主界面聊天**：类微信聊天界面，历史消息持久化、可重复播放
- **收藏夹**：右键收藏消息或导入外部音频，支持为收藏绑定快捷键一键播放
- **语音输入（ASR）**：按住快捷键说话，自动识别成文字（中英文自动语种检测）
- **音色克隆**：云端引擎支持上传/录制一段音频复刻音色，打造专属声音
- **本地离线引擎**：Genie TTS（GPT-SoVITS ONNX）纯 CPU 离线合成，音色包可扩展，断网也能用
- **发送到麦克风**：搭配 VB-CABLE 虚拟声卡，把合成语音输出为麦克风信号（应用自动检测驱动并引导安装）
- **插件化引擎**：TTS / ASR 引擎全部以插件形式提供，应用内一键安装、更新，配置（如 API Key）在设置页通用面板完成
- **一体化界面**：自绘无边框标题栏，侧边栏消息 / 收藏 / 插件 / 设置；安墨（浅色）/ 夜窗（深色）两套皮肤
- **系统托盘**：关闭主窗最小化到托盘常驻，不退出

## 插件系统

新增引擎能力全部以插件形式提供，当前官方插件：

| 插件 | 类型 | 说明 |
| --- | --- | --- |
| Edge TTS | 语音合成 | 免费、无需 Key 的微软 Edge 语音（非官方接口，可能不稳定） |
| MiniMax TTS | 语音合成 | 高质量云端合成，支持音色克隆，需 API Key |
| MiMo ASR | 语音识别 | 小米 MiMo-V2.5-ASR 云端识别，中英文自动语种检测 |
| Genie TTS | 语音合成 | GPT-SoVITS ONNX 本地推理，CPU 离线合成（首次使用需安装运行环境约 1.1GB，每个音色另约 320MB；支持离线资源包导入） |

- **内置插件库**：安装包自带全部官方插件，离线也能一键安装
- **在线插件库**：插件页点击「获取在线列表」拉取官方索引，安装 / 更新全程 SHA-256 完整性校验
- **拖入安装**：支持拖入任意插件 zip 安装（会提示来源不可信，请确认来源安全）
- **通用配置面板**：插件声明自己需要的配置项（如 API Key），设置页自动渲染对应表单，即填即用、无需重启
- **音色管理**：本地引擎支持音色安装 / 卸载 / 预加载与自定义音色包导入
- **离线资源包**：本地引擎运行环境在线下载需访问境外源，国内用户可从官方 QQ 群（690907648）/ 网盘下载资源包 zip，在应用内直接导入，无需联网
- **引擎预热**：选用本地引擎时会询问是否后台提前启动，避免第一次对话长时间等待

## 首次使用

1. 启动后点左侧边栏 ⚙️ 进入设置
2. 选择并安装 TTS 引擎（插件页一键安装）：
   - **Edge TTS**（微软）：**免费、无需 Key**，开箱即用的推荐起点
   - **MiniMax TTS**：高质量云端音色 + 音色克隆，需 API Key
   - **Genie TTS**：完全本地离线，首次使用需安装运行环境（在线下载需代理，或导入离线资源包）
3. 需要 API Key 的插件，设置页会出现对应配置面板，填入即可，立即生效
4. 如需把语音输出到麦克风（游戏内说话）：按应用引导安装 VB-Cable 虚拟声卡驱动，然后在「其他」面板打开「发送到麦克风」
5. 输入文字、回车发送即可合成播放；`Alt+V` 呼出浮窗，或在设置里开启**悬浮球**——后者在快捷键失效的游戏里尤其有用

## 技术栈

- Tauri 2 + React 19 + TypeScript + Tailwind CSS v4 + Rust
- 引擎插件化：Rust cdylib + C ABI 安全边界，动态加载 / 卸载，SHA-256 完整性校验
- TTS：MiniMax、小米 MiMo、Mossland、[Edge TTS](https://github.com/rany2/edge-tts)、GPT-SoVITS ONNX 本地推理
- ASR：小米 MiMo-V2.5-ASR

## 参与开发

```bash
npm install
npm run tauri dev      # 开发
npm run tauri build    # 打包
```

环境要求：Node.js、Rust 工具链（rustup）、Windows MSVC 构建链 + Windows SDK。

- 插件开发：见仓库 `doc/` 目录下的插件系统开发参考
- 目录结构：前端 `src/`（React 组件 + Zustand 状态）、后端 `src-tauri/`（Rust 命令与存储）、插件 `plugins/`（各引擎 crate）
