# TTSassist · 电子声带

为语言障碍者打造的语音沟通助手——**输入文字，立刻变成声音**。针对游戏等全屏场景专门优化：全局快捷键浮窗、手机遥控、虚拟麦克风输出，让你在语音软件里直接"开口说话"。

## 核心特性

- **主界面聊天**：类微信的聊天界面，历史消息本地持久化、可随时重播、可收藏
- **全屏浮窗**：`Alt+V`（可自定义）在任何界面呼出无边框置顶输入浮窗，打字 → 即时合成播放，不挡游戏画面
- **发送到虚拟麦克风**：搭配 VB-CABLE 虚拟声卡，把合成语音输出成麦克风信号，在游戏 / 语音软件里直接发声（应用自动检测驱动并引导安装）
- **手机遥控 App**：手机在同一 Wi-Fi 下当遥控器——免码配对、打字发送、切换麦克风、播放最近一条（测试阶段）
- **语音输入（ASR）**：按住快捷键说话自动转文字，中英文自动语种检测
- **实时字幕**：把听到的语音转成屏幕字幕（测试阶段）
- **音色克隆**：多个云端引擎支持上传 / 录制一段音频复刻专属音色
- **流式合成**：支持的引擎边合成边播，长句首响更快
- **数据可放自己的盘**：消息、收藏、音频等「我的数据」默认保存在系统盘的应用目录，也可自选到其他硬盘，改位置时自动搬迁
- **一体化界面**：自绘无边框标题栏，侧栏消息 / 收藏 / 插件 / 设置；安墨（浅色）/ 夜窗（深色）两套皮肤
- **系统托盘**：关闭主窗最小化到托盘常驻，不退出

## 引擎与插件

所有语音引擎以**插件**形式提供（本体不再内置任何引擎），应用内一键安装 / 更新，配置（如 API Key）在通用设置面板即填即用。当前官方插件：

| 插件 | 类型 | 说明 |
| --- | --- | --- |
| Edge TTS | 语音合成 | 免费、无需 Key 的微软 Edge 语音（非官方接口，可能不稳定），**开箱即用的推荐起点** |
| MiMo TTS | 语音合成 | 小米 MiMo 云端合成，**流式**边合边播，支持音色克隆，需 API Key |
| MOSS TTS | 语音合成 | Mossland 云端合成，**流式**、支持自定义音色，需 API Key |
| MiniMax TTS | 语音合成 | 高质量云端合成（国内流式版 / 国际版）+ 音色克隆，需 API Key |
| Fish Audio TTS | 语音合成 | 社区音色丰富、支持保存克隆音色 ID，需 API Key（在线安装） |
| MiMo ASR | 语音识别 | 小米 MiMo-V2.5-ASR 云端识别，中英文自动语种检测 |

> 多数主流引擎随安装包**预装**（离线即装）；全部引擎也在**在线插件索引**里，可随时安装 / 更新。
> **本地离线引擎（Genie / Hojo）已暂时下架**，正在按新的插件方案重新设计，将在后续版本回归。

### 插件机制

- **内置插件库**：安装包自带常见官方插件，断网也能一键安装
- **在线插件库**：插件页拉取官方索引，安装 / 更新全程 **SHA-256 完整性校验**（GitHub 不可达时自动回退 **Gitee 镜像**双通道）
- **通用配置面板**：插件声明自己需要的配置项（如 API Key），设置页自动渲染表单，即填即用、无需重启
- **我的音色**：跨引擎统一的自定义音色管理（保存 / 切换你自己的音色 ID），只在引擎支持云端音色库时出现

## 首次使用

1. 启动后点左侧 ⚙️ 进入设置，或直接到「插件」页
2. 选一个语音引擎一键安装并设为当前引擎：
   - **Edge TTS**：免费、无需 Key，最快上手
   - **MiMo / MOSS / MiniMax / Fish**：云端高质量，需向运营商申请 API Key，填入即用
3. 想在游戏 / 语音软件里发声：按引导安装 **VB-CABLE** 虚拟声卡驱动，在「其他」面板打开「发送到麦克风」，并在语音软件（如 KOOK）里把麦克风选为 `CABLE Output`
4. 想用手机遥控：手机连同一 Wi-Fi，装「电子声带遥控」App，在设备列表点你的电脑配对（PC 上确认）
5. 输入文字、回车发送即可合成播放；`Alt+V` 随时呼出浮窗

## 数据存放位置

应用的数据分成三类，界面上就叫这几个名字：

| 类别 | 里面有什么 | 位置 |
| --- | --- | --- |
| **配置** | 设置（快捷键 / 引擎 / API Key / 音色 / 皮肤 / 窗口尺寸）、遥控配对、**数据位置指针** `storage.json`、运行日志、迁移备份 | `%APPDATA%\com.voiceassist.app\`（卸载默认保留） |
| **我的数据** | 消息记录、收藏、字幕历史、合成音频、克隆样本、插件的模型与运行环境 | 默认同上，可自选到任意盘（如 `D:\VoiceAssistData\`） |
| **插件** | 各引擎的程序本体（`manifest.json` + `plugin.dll`），单个只有 1–2 MB | 安装目录 `\plugins\`，写不进去时自动回退到「我的数据」下 |

**临时文件**（`cache\`、`downloads\`、`logs\`）是三类里唯一可以被清理的东西，会随使用增长但不含你的内容。

- **想放到别的盘**：设置 → 存储 → 「更改数据位置」，选一个目录即可，应用会把「我的数据」搬过去（目标目录里已存在的同名文件不会被覆盖，旧位置的内容转成备份目录保留）。
- **卸载不丢数据**：卸载向导里的两个勾选框（删除配置 / 删除我的数据）**默认都不勾**，直接卸载再重装，数据和配置都还在。
- **重装后怎么找回**：数据位置记在配置目录的 `storage.json` 里，卸载默认不删这个文件——重装后应用按它自动读回你自选位置的数据，无需手工处理。
- **「清理」按钮绝不碰珍贵资产**：只清临时文件，不会删除消息、收藏、音频与克隆样本。

## 技术栈

- Tauri 2 + React 19 + TypeScript + Tailwind CSS v4 + Rust
- 引擎插件化：Rust cdylib + C ABI 安全边界，动态加载，SHA-256 完整性校验
- TTS：Edge、小米 MiMo、Mossland、MiniMax、Fish Audio 等云端引擎（均以插件提供）
- ASR：小米 MiMo-V2.5-ASR
- 遥控：局域网 WebSocket + mDNS 发现 + 免码配对（手机 App 为 Flutter）

## 参与开发

```bash
npm install
npm run tauri dev      # 开发
npm run tauri build    # 打包
```

环境要求：Node.js、Rust 工具链（rustup）、Windows MSVC 构建链 + Windows SDK。

- 目录结构：前端 `src/`（React + Zustand）、后端 `src-tauri/`（Rust 命令与存储）、插件 `plugins/`（各引擎 crate）、遥控 App `remote-app/`（Flutter）
- 插件接口规范（manifest、C ABI）见项目维护文档，欢迎通过 Issues 交流
