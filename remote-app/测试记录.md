## 二、构建环境坑（本机特有，均已绕过）

| 坑 | 现象 | 绕过 |
|---|---|---|
| google()/mavenCentral() 直连挂起 | gradle 配置阶段静默卡死 | `~/.gradle/init.d/aliyun-mirror.gradle` 全局镜像前置（含 included build） |
| flutter_tools/gradle 独立仓库 | 主工程镜像不覆盖 included build | 同上 init 脚本（settingsEvaluated 清仓重加） |
| NDK 自动下载挂起（dl.google.com） | AGP/flutter tool 装 NDK 卡死并留损坏目录 | 代理 `127.0.0.1:7897` 下载 r28c zip 手工放置 `Sdk\ndk\28.2.13676358` |
| 损坏 NDK 目录嵌套 | Move-Item 把完整 NDK 嵌进残留目录；MAX_PATH 删不掉 | `[System.IO.Directory]::Delete("\\?\…", $true)` 清残留后重放 |
| 安全软件占 Kotlin 增量缓存句柄 | `:webview_flutter_android:compileDebugKotlin` Could not close incremental caches | `android/gradle.properties` 加 `kotlin.incremental=false` |
| flutter-io.cn 镜像需鉴权 | SDK 下载失败 | Flutter SDK 走官方 storage.googleapis.com |
| 改 applicationId 后启动闪退 | ClassNotFoundException: com.voiceassist.remote.MainActivity（flutter create 生成的 Kotlin 源包名仍是旧的 voiceassist_remote） | MainActivity.kt 移到 kotlin/com/voiceassist/remote/ 并改 package 声明，旧文件删除；模拟器复现 logcat 定位 |
| tauri build 抹掉未内置插件 | target/release/plugins 按 resources/plugins/*.zip 重建，lan-remote 目录与 registry 记录消失 | lan-remote zip 拷入 src-tauri/resources/plugins/ 随构建内置；registry 用 package.ps1 -Install 或手工注册 |
| registry.json 带 BOM | PowerShell Set-Content -Encoding UTF8 写 BOM，宿主 serde_json 解析失败→全部插件不加载（WS 端口拒连） | [System.IO.File]::WriteAllText 无 BOM 重写；以后改 registry 禁用 Set-Content UTF8 |
| 手机发现不了 PC（mDNS） | Windows 防火墙无 UDP 5353 入站规则（只有 Edge 有）→ 手机查询包被拦，发现列表永远空 | 管理员 PowerShell 加规则：`netsh advfirewall firewall add rule name="电子声带 mDNS 发现 (UDP 5353)" dir=in action=allow protocol=UDP localport=5353 profile=private`；TCP 45271 同法。沙箱内启动的宿主写 AppData 被拒（os error 5），display 字段上屏需用户自启实例验证 |
| 模拟器发现不了 PC（mDNS） | 模拟器在隔离虚拟网络（10.0.2.x），收不到真实局域网广播 | discovery.dart 模拟器桥接：检测 !isPhysicalDevice 后周期探测宿主别名端口，登记进发现列表（真机不受影响） |
| 模拟器 10.0.2.2 的 WS 握手不稳定 | qemu slirp NAT 下部分连接服务端报 Handshake not finished | 模拟器测试前置 `adb reverse tcp:45271 tcp:45271`，桥接探测优先 127.0.0.1（adb 隧道），10.0.2.2 兜底 |
| PC 确认弹窗被遮住 | tauri-plugin-dialog 无父级 MessageBox，宿主退居后台时被前台窗口完全挡住，用户看不到 | bridge.rs 改 Win32 MessageBoxW + MB_SYSTEMMODAL/MB_SETFOREGROUND 系统置顶（win32.rs confirm_yes_no） |
| 并发连接相互踩踏 | 旧连接的 onDone 回调触发新会话的重连调度，形成 1s 认证重连风暴；error 帧乱清 token | remote_client.dart 连接世代号（_gen）：旧连接回调一律失效，teardown 主动关旧通道；session.dart 仅未鉴权态的 error 才清 token |

## 二·B、v3 改版对测新坑（2026-08-30）

| 坑 | 现象 | 绕过 |
|---|---|---|
| WebView 平台视图吞触摸 | 主遥控页点 logo（GrokLogo 内嵌 WebView）无响应，断开确认弹窗不弹 | grok_logo.dart 用 IgnorePointer 包 WebViewWidget（logo 纯装饰 followPointer:false），点击穿透到外层 PressScale |
| 模拟器启动后 adb 长期 offline | 冷启动 qemu 进程在但 adb 一直 offline 超 8 分钟，且最终进程自行消失（疑似内存不足崩溃） | 杀 qemu 重启用 `-no-snapshot -gpu swiftshader_indirect -no-boot-anim`；上线后需重跑 `adb reverse tcp:45271 tcp:45271` |
| 模拟器刚开机 am start 假报错 | pm clear 后立刻 am start 报 Activity does not exist，但包实际在 | 等 5–10 秒重试即可（包管理器未就绪） |
| install -r 不重启进程 | 覆盖安装后 am start 只调起旧进程，新代码未生效（表现为修复「没生效」） | `am force-stop com.voiceassist.remote` 后再 am start |
| IAB 截图管线间歇挂死 | 内置浏览器截图报 surface preparation timed out / activity capture failed，scroll 偶发 30s 超时 | 关标签页重开 + 等数秒；列表内部滚动会挂 CUA，改用页面级操作或真机验证 |
| **PC 端 mDNS 静默失效（真机发现不了 PC）** | 真机发现列表空，手动 IP 正常；本机 zeroconf 浏览也空；mdns-sd 已注册但组播/单播查询均不应答 | **根因：Windows UDP 5353 被多进程抢占**——Steam/QQ 等各持 10+ 条 5353 绑定且随时重绑，Windows 把包只投递给「最后绑定者」，mdns-sd 监听被顶掉。本机实验实锤：同样绑法 python 绑 5353 立即收到查询，mdns-sd 无反应。PC 侧无法根治（杀进程不可持续），**App 侧加子网扫描兜底**：discovery.dart 周期（5s）对本机各 IPv4 /24 并发探测 45271（300ms 超时，排除本机自身 IP——adb reverse 会在手机端开监听造成自命中误报），与 mDNS 结果合并 |
| **真机 WiFi 抖动后「一直连接中」** | 关/开 WiFi 后配对页永远「连接中…」，重启 App 立刻连上 | 根因：remote_client.dart connect() 失败分支 `await ch.sink.close()`——无路由时 sink.close() 永久挂起，connect 不返回，session 退避链条饿死。修复：close 改 fire-and-forget（世代号已使旧回调失效）+ session._connect 加 10s 看门狗。真机飞行模式 12s 实测：恢复后自动回主遥控页 |
| 防火墙规则 Profile 不匹配 | 规则默认 Private，但 Windows 把 WiFi 判为 Public 时规则整体失效（mDNS/TCP 全拦） | `Set-NetConnectionProfile -InterfaceAlias WLAN -NetworkCategory Private` 把家庭网络设为专用；规则按端口添加时同时考虑按 exe 放行 |
