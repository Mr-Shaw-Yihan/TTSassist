# hojo-tts 插件复验测试步骤

> 已完成两轮端到端实测（ctypes 直载 plugin.dll 模拟宿主调用，2026-08-24）：
> 第一轮验证环境安装→模型下载→合成全链路；第二轮（v0.1.0 音色表修正后）
> 验证新预置音色（默认女声 + ASR 转写文本男声）合成与性别闭环
> （合成产物 F0：女声 312Hz / 男声 117Hz，与标注一致）。
> 实测环境（Python+模型 1.7GB）已预置于宿主插件数据目录，GUI 复验**无需下载**。

## 一、GUI 复验（宿主真实链路，约 3 分钟）

1. 启动 VoiceAssist（`src-tauri\target\release\voiceassist.exe`）。
2. 设置 → 语音合成：引擎选「Hojo TTS（本地·离线）」。
3. 首次选引擎时宿主触发「安装运行环境」：环境已就位，各阶段数秒走完
   （引擎预热约 30~60 秒）。
4. 发送「你好，这是本地语音合成测试。」→ 默认音色「女声·中文一」，
   首句约 30~60 秒，之后单句 2~6 秒。
5. 换中英混读一句（如「今天天气不错，let's go shopping!」）验证双语。

## 二、音色管理复验

1. 设置 → 音色管理（hojo-tts 下）：应看到 5 个预置音色
   （女声·中文一/二/三、女声·英文、男声·英文），默认音色已安装，
   其余标「待下载」。
2. 安装「男声·英文」（几百 KB，秒级）→ 切换该音色，用英文文本合成验证
   （参考文本来自 ASR 转写，克隆质量应与默认音色相当）。
3. 卸载再装回，确认删除/安装正常。

## 三、自备音色导入复验（克隆自己的声音）

1. 自建目录（名字即音色 id，仅字母/数字/`-`/`_`），例如 `my-voice/`：
   - `ref.wav`：录 5~10 秒干净人声
   - `voice.json`：`{"label": "我的声音", "text": "录音的逐字文本"}`
2. 设置 → 音色管理 → 导入音色包 → 选 `my-voice/` → 合成验证音色相似度。

## 四、排障

- 服务端日志（第一现场）：`plugins\hojo-tts\data\hojo-server.log`
- 端口号：`plugins\hojo-tts\data\server-port`；健康检查
  `curl http://127.0.0.1:<端口>/health`
- 重置环境（重新下载）：关闭应用后删
  `plugins\hojo-tts\data\python`（重装依赖）、`...\models`（重下模型）、
  `...\voices`（重装音色）任一目录，下次合成自动补齐。
- pip 安装失败：插件内置多源回退（清华 → 腾讯 → 官方），个别网络环境仍
  失败时可用环境变量 `HOJO_TTS_PIP_INDEX_URL` 指定可用源后重试。

## 五、已知边界（设计内行为）

- 插件无任何用户配置界面：网络容错全部内置（模型下载多端点回退、pip 多源
  回退、音色下载双源回退），后续离线资源包经 Gitee/群文件分发。
- 合成按句串行（CPU 推理锁），长文本耗时随长度线性增长。
- 离线资源包导入：宿主 `import_offline_resources` 当前是 genie 专属结构校验，
  本插件按「`data\models\` 放齐 8 个文件 = 等价在线下载完成」预留了结构，
  手动拷贝即可离线部署；通用化宿主命令需另行立项（不在本次范围）。
- 上游无中文男声素材：预置表没有中文男声，需要时自录导入（见三）。
