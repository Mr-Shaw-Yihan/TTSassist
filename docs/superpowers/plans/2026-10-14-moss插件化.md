# MOSS 插件化（`moss-tts` 预装 + 全插件进索引）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL：用 superpowers:executing-plans 逐任务实现。步骤用 `- [ ]` 跟踪，**每完成一项即把对应 `- [ ]` 改成 `- [x]`**。
> 设计依据：`docs/superpowers/specs/2026-10-14-moss插件化-design.md`。

**Goal:** 把内置 MOSS 引擎改造成预装插件 `moss-tts`，本体不再有任何内置 TTS 引擎；老用户 key/音色自动迁移、装好即用不变；所有引擎插件同时进在线索引。

**Architecture:** 仿 mimo-tts 插件化：新建 cdylib crate（`va_tts_plugin!` 非流式，读 `MOSS_TTS_API_KEY` env）→ 打包进 `resources/plugins` 预装 + 进索引 → 宿主删内置 `tts/moss.rs` 与 `"moss"` 分支 → `migrate_legacy_engine` 增 `moss→moss-tts`（key→`plugin_config`、voice→`plugin_voices`）→ base-hygiene 更新基线。

**Tech Stack:** Rust（插件 C ABI + 宿主 commands/plugins/storage）、React/TS（设置/音色面板）、PowerShell（package/publish/verify-index）、既有 edge/mimo/minimax 插件范式。

## 🔎 执行中发现（需修正设计，Task 2 阻塞于此）

- 前端事实（`settingsStore.test.ts`/`src/types/index.ts`）：MOSS 有 **三个** 设置项：`moss_api_key`、`moss_voice_id`（UUID）、**`moss_voices: {name,voice_id}[]`**（自定义音色列表，默认“曼波”）。→ MOSS 像 MiniMax 的“我的音色”，不是固定下拉。
- 后果：① **Task 1 迁移不完整**（只搬了 `moss_voice_id`，没搬 `moss_voices` 列表）→ 需补一个子任务。② **crate 不能硬编 voices_json**，需接“自定义音色”机制。
- **待定设计点**：`moss_voices` 如何映射？候选：复用通用插件自定义音色机制（如 minimax `plugin_custom_voices` 同类）/ 存 `plugin_config["moss-tts"].voices`（list）/ 插件自提供音色 API。需先查清 minimax/现有“我的音色”存储形状再定。
- `doc/tts-api/moss-tts.md`（moss.rs 引用的文档）可能含音色列表/新增音色 API，设计前需参考。

---

【修正上面“候选”】查清：`plugin_voices` 仅为“每插件一个选中值”（`HashMap<String,String>`），**并无通用“自定义音色列表”机制**；MOSS `moss_voices: Vec<MossVoice>` 与 MiniMax `minimax_global_cloned_voices: Vec<String>` 都是设置在根部的**引擎专属字段**（AGENTS §70 基座债）。因此 A/B/C 实为：A 保留 moss_voices 为宿主字段（插件经桥/env 读，同 minimax）/ B 新建通用 `plugin_custom_voices` 机制（彻底但面大）/ C 音色完全下沉插件。需用户定 A/B/C。

fn moss迁移到插件并搬key音色() {

- [x] **Step 3 实现**：在 `migrate_legacy_engine` 的 edge/mimo 之后追加：
```rust
// 3) 内置 moss → moss-tts 插件；key 迁 plugin_config、voice 迁 plugin_voices
if obj.get("tts_engine").and_then(|x| x.as_str()) == Some("moss") {
    obj.insert("tts_engine".into(), serde_json::Value::String("moss-tts".into()));
    if let Some(k) = obj.get("moss_api_key").and_then(|x| x.as_str()).map(str::to_string) {
        if !k.is_empty() {
            set_plugin_config_if_absent(&mut obj, "moss-tts", "api_key", &k); // 仿 set_plugin_voice_if_absent
        }
    }
    let voice = obj.get("moss_voice_id").and_then(|x| x.as_str())
        .filter(|s| !s.is_empty()).unwrap_or("default").to_string();
    set_plugin_voice_if_absent(&mut obj, "moss-tts", voice);
}
```
