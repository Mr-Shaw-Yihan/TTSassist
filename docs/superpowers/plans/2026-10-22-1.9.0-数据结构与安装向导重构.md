# 1.9.0 数据结构重构 + 安装向导 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: 用 superpowers:subagent-driven-development 或 superpowers:executing-plans 逐任务执行。步骤用 `- [ ]` 复选框跟踪。
> **本计划由两个 agent 并行执行**（Agent A = 存储与打包线，Agent B = 界面与体验线）。**开工前必须先读「文件独占权」表**，越界改文件会造成合并冲突。

**Goal:** 让「我的数据」默认落回 `%APPDATA%`（卸载/升级不丢），提供用户自选存放位置并自动迁移；移除本地引擎插件（genie-tts / hojo-tts）使本体干净；安装向导汉化 + 现代化视觉 + 卸载时可选删除项；修掉 4 个体验缺陷。

**Architecture:** 存储层已有 `config_root`（`%APPDATA%\com.voiceassist.app`）/ `content_root`（当前默认 `<exe>\data`）/ `plugins_root`（`<exe>\plugins`）三根解析与 `storage.json` 指针、`migrate_storage_now`、备份目录、迁移通知等机制。本次**不新建体系，只改默认落点 + 补「用户选新位置并迁移」的最后一环**（命令 + UI + 首启弹窗）。安装侧新建真实存在的 `windows/installer-hooks.nsh` 承载汉化与卸载勾选项（当前 `tauri.conf.json` 指向的这个文件**不存在**，属悬空引用）。

**Tech Stack:** Tauri v2（Rust）+ React 19 / TypeScript + zustand + Tailwind；NSIS（Tauri 内置模板 + installerHooks）；vitest + `cargo test`。

## 环境注意（两个 agent 都必须遵守）

1. `cargo` 命令前设 `$env:CARGO_HTTP_CHECK_REVOKE='false'`（本机证书吊销检查会失败）
2. **PowerShell 里 `git … 2>&1 | …` 管道会触发 git.exe「拒绝访问」** → git 命令**不要接管道**
3. `git add` **逐个文件**，**禁止 `git add -A` / `git add .`**（工作区有多条工作线共享同一 .git）
4. 动手前跑 `git branch -vv && git status --short && git log --oneline -5`，发现与本任务无关的未提交改动 → **停下报告**
5. 红线（每次都要用户明确同意）：`git reset --hard`、`git clean`、`git checkout -- <file>`、删未跟踪文件、合并到 main、push、打 tag、发布
6. commit message **只写中文正文，不加 `Co-Authored-By`**
7. 版本号三处同步（`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json`、`package.json`）由 `bump-version.ps1` 负责，**本次不改版本号**（已是 1.9.0）
8. 收工更新 `doc/看板-1.9.0.html` 与 `doc/归档/工作线状态.md`
9. **门禁取数必须贴实际输出行，不得只给结论**（V3 发现 A11 自报「四守卫 exit 0」，实测 `check-log-hygiene` exit 1）
10. **`log_info!` 等日志宏里不要出现 `text`/`content`/`title`/`body`/`user_input`/`prompt` 这些变量名**（`check-log-hygiene` 按命名启发式判定为「用户文本入日志」）。若变量装的是应用自己拼的通知/路径/id，**改名为 `notice` 等语义准确的名字**（根因修复），不要用 `// allowlog:` 豁免注释堆积
11. **worktree 之间不共享 `node_modules`、`src-tauri/target`、`plugins/target`、`plugins/target-test`**，新 worktree 需 `npm install`，首次 `cargo test` 会全量编译（5–15 分钟属正常）
12. `npx vitest run` 用 `--reporter=dot`（本机 vitest v5 **没有 `basic` reporter**）；**不要给 vitest/git 命令加 `2>$null` 或 `2>&1 |`**，前者会吞掉输出、后者会让 git.exe 报「拒绝访问」
